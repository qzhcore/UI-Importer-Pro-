From file to hierarchy

A clean handoff in six steps.

The importer validates the file, rebuilds its structure under StarterGui, embeds supported artwork, and keeps source metadata for reliable scripting.

01

Install the plugin

Place the release .rbxm in Studio's Plugins Folder, restart Studio, and open UI Importer Pro.

02

Prepare layer names

Use names such as [TextButton] Buy or [Scroll] Inventory when the intended Roblox class matters.

03

Choose the target

Generate a ScreenGui for menus, SurfaceGui for Parts, or BillboardGui for world-space UI.

04

Choose sizing

Fill the safe screen with Adaptive or protect artwork proportions with Preserve aspect.

05

Import and inspect

The selected result appears under StarterGui with a Canvas, embedded artwork, tags, and attributes.

06

Script and test

Connect the named semantic controls, then test phone, tablet, desktop, and gamepad behavior.

Responsive choices

Pick the behavior your design expects.

No single mode is right for every composition. The plugin makes the tradeoff explicit before the import.

Flexible layouts

Adaptive

Fills the device-safe display using scale-based geometry.

  • Best for full-screen menus and HUDs
  • Uses the available screen area
  • Can stretch fixed-ratio artwork
Artwork-heavy UI

Preserve aspect

Locks the canvas to the source document's aspect ratio.

  • Prevents visual distortion
  • Best for illustrated panels and menus
  • May letterbox on different screens

Semantic overlays

Script the controls, keep the artwork.

When Photoshop effects are present, RenderedDesign preserves the exact look while aligned Roblox controls remain available for interaction.

local gui = playerGui:WaitForChild(
    "DGfishingGameFrame5"
)
local canvas = gui:WaitForChild("Canvas")
local equip = canvas:FindFirstChild(
    "EquipButton",
    true
)

if equip and equip:IsA("GuiButton") then
    equip.Activated:Connect(function()
        print("Equip selected")
    end)
end

Which PSD files are supported?

Standard PSD, RGB, 8-bit documents with raw or RLE layer pixels, up to Studio's 100 MB file-picker limit. PSB, CMYK, 16/32-bit, and ZIP-compressed individual layer pixels are not supported yet.

Why is there a RenderedDesign object?

It preserves the exact Photoshop composite when the source uses effects Roblox cannot recreate natively. Transparent, named Roblox objects remain aligned above it for scripting.

Does responsive mean every design automatically works in portrait?

No. The importer produces scale-based geometry and safe-area behavior, but a flat desktop composition cannot invent a purpose-designed mobile layout. Test every target device.

What does native Figma support include?

Frames, groups, components, vectors, shapes, text, solid fills, corners, strokes, and hierarchy. Embedded bitmap fills are placeholders in this beta.
