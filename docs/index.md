# UI Importer Pro

Convert layered Photoshop PSD and native Figma `.fig` files into organized,
responsive, script-ready Roblox UI.

## The import flow

1. Install `UIImporterPro.rbxm` in Studio's Plugins folder.
2. Open **UI Importer Pro** from the Plugins tab.
3. Choose `ScreenGui`, `SurfaceGui`, or `BillboardGui`.
4. Choose **Adaptive** or **Preserve aspect**.
5. Import a compatible PSD or native `.fig`.
6. Inspect the generated root under `StarterGui`.
7. Script the named semantic controls and test in Device Emulator.

This is beta software. Keep your original design files and test generated UI
before using it in a live experience.
