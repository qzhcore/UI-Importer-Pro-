# Security Policy

## Supported versions

Only the latest published beta receives security fixes.

## Report a vulnerability privately

Do not open a public issue for a vulnerability, leaked credential, unsafe file
handling problem, or exploit that could affect Roblox Studio users.

Use GitHub's private vulnerability reporting feature on this repository. Include
the affected version, impact, reproduction steps, and a minimal non-confidential
test file when possible.

Never send Roblox account cookies, passwords, API keys, private client artwork,
or personal information.

The maintainers will acknowledge a complete report, investigate it, and
coordinate disclosure after a fix is available.
